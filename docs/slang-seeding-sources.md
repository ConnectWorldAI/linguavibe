## Ingestion Strategy

### What We Extract from Each Source:
1. **Phrases** — the actual slang/expression
2. **Region** — which country/city uses it
3. **Meaning** — English translation + context
4. **Formality** — street/casual/formal
5. **Pronunciation notes** — how it actually sounds (dropped letters, speed, etc.)
6. **Textbook equivalent** — what a textbook would teach instead
7. **Usage scenario** — when/where/with whom to use it
8. **Age group** — who uses this (young, all ages, older)
9. **Comparison** — how other regions say the same thing differently

### Content Types to Seed:
- Emotions expressed differently by region
- Greetings and goodbyes by country
- Slang for common situations (angry, happy, tired, hungry, in love)
- Street talk vs formal talk
- Code-switching patterns
- Terms of endearment by region
- Insults/exclamations by region (with appropriate warnings)
- Food/drink ordering differences
- Music/party vocabulary by region
