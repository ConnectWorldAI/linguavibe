# Fluence — Global Language & Slang Data Strategy

## Core Principle

Every country, every city, every neighborhood that speaks differently gets its own entry. Panama Spanish is NOT Costa Rica Spanish is NOT Cuba Spanish. Brazilian Portuguese from Rio is NOT from São Paulo. Egyptian Arabic is NOT Lebanese Arabic. This is what makes Fluence different from every other language app — we don't teach "generic Spanish," we teach the REAL language people actually speak in specific places.

## Data Pipeline Architecture

### How New Slang Gets Into Fluence

```
1. DETECTION
   ├── Social media monitors (Twitter, TikTok, Reddit, Instagram)
   ├── Music release monitors (new songs with new slang)
   ├── User submissions (students flag words they hear IRL)
   ├── Community validators (native speakers submit)
   └── News/media scrapers (current events vocabulary)

2. VERIFICATION (GPT-4o + Human)
   ├── Is this real? (Cross-reference 3+ sources)
   ├── Is it widely used? (Frequency analysis)
   ├── Which region? (Geographic tagging)
   ├── Which age group? (Demographic tagging)
   ├── Is it offensive? (Content classification)
   └── Is it temporary or lasting? (Trend vs. permanent)

3. ENRICHMENT
   ├── Add pronunciation (Forvo or AI-generated)
   ├── Add example sentences (Tatoeba or AI-generated)
   ├── Add cultural context (when/where/how to use)
   ├── Add formality level (street, casual, formal, business)
   ├── Add related words/synonyms in other dialects
   └── Tag with lesson compatibility (which level can learn this)

4. DEPLOYMENT
   ├── Added to vocabulary database
   ├── Teacher AI can now use it in conversations
   ├── Appears in "What's Trending" feed
   ├── Integrated into relevant lessons
   └── Push notification to interested users
```

### Update Frequency by Source

| Source Type | Check Frequency | Expected New Entries |
|-------------|----------------|-------------------|
| Social media trending | Every 6 hours | 10-50 new candidates/day |
| Music releases | Weekly | 5-20 new slang terms/week |
| User submissions | Real-time | 50-200/day at scale |
| Community validators | Daily batch | 20-50 verified/day |
| News/media | Daily | 5-10 new terms/day |
| Academic/linguistic sources | Monthly | 50-100 verified entries/month |

## Competitive Moat

No other language app has:
1. **City-level granularity** — We don't teach "Spanish," we teach "Santo Domingo Spanish" or "Medellín Spanish"
2. **Real-time slang updates** — Our database updates daily, not annually
3. **Cross-dialect mapping** — We show how the same concept is expressed differently across regions
4. **Native speaker verification** — Every entry verified by real people from that region
5. **Music-sourced vocabulary** — We detect new slang from songs before it hits dictionaries
6. **Cultural context** — We don't just translate, we explain WHEN and WHERE to use each word

This data moat becomes more valuable over time and is nearly impossible to replicate.
