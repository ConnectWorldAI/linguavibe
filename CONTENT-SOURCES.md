## How Sources Will Be Used

1. **AI Teacher Training** — Dialect-specific vocabulary, pronunciation patterns, and cultural context fed into teacher personas (e.g., Maria from Santo Domingo uses Dominican slang from these sources).

2. **Flashcard Generation** — Real-world phrases and slang extracted from content creators' posts become flashcard decks tagged by region.

3. **Trending Content Feed** — Social media posts, reels, and videos surface in the Explore/Search tab with translation overlays (tiered by membership).

4. **Pronunciation Models** — Audio/video from native speakers used as reference for pronunciation scoring and accent training.

5. **Cultural Calendar** — Holidays, events, and trending topics from these sources inform just-in-time vocabulary lessons.

---

## Pipeline (Future Implementation)

1. Monitor sources via API or scraping
2. Extract text, audio, and video content
3. Run through enrichment pipeline (verify, tag by region/difficulty)
4. Community validators confirm accuracy
5. Content enters teaching database
6. AI teachers reference in lessons
