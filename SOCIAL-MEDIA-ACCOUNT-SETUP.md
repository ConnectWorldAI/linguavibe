## Assembly-Line Workflow (Fastest Method)

Instead of setting up one influencer completely across all 3 platforms, do it by platform:

**Day 1: Create all 12 Gmail accounts** (30 min)
- Use Chrome profiles or incognito windows
- Write down all passwords in a password manager

**Day 2: Create all 12 TikTok accounts** (1-2 hours)
- Open each Gmail, sign up for TikTok
- Set username, bio, profile photo
- Space them out (don't create all 12 in 5 minutes — platforms flag this)

**Day 3: Create all 12 Instagram accounts** (1-2 hours)
- Same process, use each Gmail
- Switch to Professional/Creator account
- Set up profile

**Day 4: Create all 12 YouTube channels** (1 hour)
- Sign into each Gmail on YouTube
- Create channel with custom name
- Fill in description and links

**Day 5: Final touches** (1 hour)
- Upload all profile photos
- Add all links
- Cross-link accounts (TikTok bio → IG, IG bio → YouTube, etc.)
- Verify all accounts are live and public

---

## Tips to Avoid Account Flags

1. **Space out creation** — Don't create more than 3-4 accounts per platform per day
2. **Use different IP addresses** — VPN or mobile data between batches
3. **Vary the bios slightly** — Don't copy-paste identical text
4. **Post first content within 24 hours** — Empty accounts get flagged faster
5. **Use real profile photos** — Accounts with avatars look more legitimate
6. **Enable 2FA on all accounts** — Protects against lockouts
7. **Save all credentials** — Use a password manager (1Password, Bitwarden, LastPass)
